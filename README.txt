American Dentistry - Queens, NY website

1. Open index.html in any browser (or upload the whole folder to your hosting).
2. Booking form: inside index.html (section id="contact"). On submit it opens WhatsApp (+1 929 757 4718) with the patient's details filled in.
3. Hero video: put your mp4 in assets/video/ and set <video ... src="assets/video/hero.mp4">. The video then plays automatically as a looping hero background. For a scroll-controlled video (plays as the user scrolls) also add the attribute data-scrub="1" and keep the video short (5-10 sec).
4. Before/after photos: put images in assets/images/ and edit the "cases" list in the script, e.g. {t:'Veneers',before:'assets/images/v-before.jpg',after:'assets/images/v-after.jpg'}.
